# GymDuo TV

Ricevitore browser pubblico. Nessun sorgente privato Android, chiave di firma, credenziale utente o diagnostica personale.

Associazione tramite codice temporaneo generato dalla TV; il telefono autenticato autorizza una capability di sola visualizzazione della sessione. Il ricevitore non usa Firebase Authentication e non può leggere schede, storico o misure personali.

Chromium e WebKit testati su PC con Firebase emulator; nessuna promessa di compatibilità universale o test su televisori fisici. Richiede Internet su TV e telefono.

Timer locale; Firestore viene aggiornato sulle azioni e con heartbeat limitati, non ogni secondo.
